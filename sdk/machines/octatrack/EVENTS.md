# Octatrack events at base-owned stock sites

Generated by `sdk/machines/octatrack/events.py` from `events.json`: edit the registry, then run
`python3 -B sdk/machines/octatrack/events.py --write`.

The Modwerk base owns these stock sites and turns them into events, as Elekloader's core does for
`ev_tick` and the others (rule 4: do not patch the shared sites, subscribe). A runtime package subscribes
with `{"event", "fn", "order"}` (a module's `runtime.json`, or `build.py --subscribe EVENT:FN:ORDER`);
the loader keeps each event's handlers in (order, module id) order and refuses any package that
patches one of these sites. Handlers use the C convention: arguments on the stack, d0-d1/a0-a1 free,
everything else kept, the result in d0. C modules include `include/modwerk_events.h`.

## Why this order

- `ev_play_increment`: sdk/octabam/modules/poly8/composition.json replaces Repitch's 0x40004100 detour with POLY8's mr_rate_hook, which takes POLY tracks first and passes the others to rate_hook. POLY8 also forces a POLY track's live TSTR off (poly_config_tstr), so REPITCH never acts on one.
- `ev_voice_bind`: POLY8's mr_stop_voice checks its renderer state before anything else, then Mute Modes' gate (its mr_mute_suppressed, a copy of fresh_bind's test, when fresh_bind is linked), and only then discards the track's extension voices (ev_voice_bind_run).
- `ev_voice_bind_run`: In POLY8 + Mute Modes the extension voices are discarded only when the reset is not dropped (mr_mute_suppressed returns first).
